Gráfico Vectorial: Casa bajo el sol

El gráfico vectorial anterior representa una casa sencilla al aire libre. La composición utiliza un círculo amarillo para ilustrar el sol, una línea verde gruesa que funciona como la base o el césped, un rectángulo para la estructura principal de la vivienda y un polígono de tres vértices que simula un techo a dos aguas.

Gráfica 2: Popularidad de Lenguajes de Programación (Datos Reales)

Esta gráfica de barras representa estadísticas aproximadas del uso de los lenguajes de programación más populares. Se construyó utilizando una etiqueta <line> para el eje base, cuatro etiquetas <rect> con diferentes alturas para representar los datos, y etiquetas <text> bajo cada barra para su correcta identificación.
