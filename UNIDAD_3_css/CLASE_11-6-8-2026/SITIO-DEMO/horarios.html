Cómo entregar una práctica

  1. Traer los cambios del git pull.
  2. Crear la rama nueva de la sesión con "git switch -c NombreRama".
  3. Trabajar y crear commits atómicos.
  4. Subir rama con "git push".
  5. Abrir el pull request en GitHub.
  6. Revisar y fusionar el pull request.
  7. Volver al MAIN.
  8. Eliminar rama creada con "git branch -d NombreRama".

Glosario Git

Commit:
Instantánea permanente del proyecto en un momento dado.
Rama
Linea de trabajo paralela que no afecta main.
Pull Request
Solicitud de revisión para incorporar cambios de una rama o rama.
